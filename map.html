Read this before treating it as a roadmap. Volume ≠ value — this axis counts how often something came up, not how much it's worth; the value axis arrives once behavioral data is wired in. Clustering is heuristic keyword matching (first-match-wins rules), not embeddings — a card lands in one theme even if it touches several, and wording quirks can misfile it. “Other” is a catch-all for cards no rule matched.
